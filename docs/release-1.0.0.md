# 1.0.0 发布验证

日期：2026-11-08。

用户在最终 0.1.1 测试后确认“测试已经通过，可以出正式版。可以上传github”。该确认未提供额外的测试时长、采样率或解调测量，因此不扩展已有量化测试结论。

1.0.0 保留该测试版的采集、DDC、SpyServer、固件及缓冲配置。程序变化仅为 Android 版本号、界面版本文字、日志文件建议名称和后端版本文字；发布材料及构建输出名称同步更新。

测试基线为一加 8T / Android 16 / KernelSU root / 独立供电 USB 3 Hub：

| IQ 采样率 | 手机本机连续接收 | USB 错误 | 原始 / IQ 队列丢样 |
|---|---:|---:|---:|
| 1 MS/s | 30 秒 | 0 | 0 / 0 |
| 2 MS/s | 20 秒 | 0 | 0 / 0 |
| 4 MS/s | 20 秒 | 0 | 0 / 0 |

固件加载、USB 3 枚举、频率及增益切换、停止后再接收、Android ARM64 DDC 与队列测试已通过。原始记录见 [android-test-0.1.1.txt](android-test-0.1.1.txt)。调频会停流和重建 DDC，测试中记录到调频期间样本间断。

正式 APK 单独核对版本、签名、固件哈希、AArch64 ELF、16 KiB 页面及 ZIP 对齐；打包检查结果见 [release-package-1.0.0.txt](release-package-1.0.0.txt)。延续原签名，以便直接覆盖安装测试版。签名私钥不随源码发布。

已在同一手机覆盖安装 1.0.0，核对安装版本、启动界面和真实 RX888 USB 后端 `READY`，并确认内核兼容参数恢复原值；记录见 [upgrade-1.0.0.txt](upgrade-1.0.0.txt)。

现有量化验证为短时测试。HF 路径、其他手机及长时间连续运行仍待验证；没有单独的 OnAir 解调听感测量记录。
