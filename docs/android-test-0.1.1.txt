RX888 Android Bridge 0.1.1 实机验证
日期：2026-11-08
设备：一加 8T KB2000 / Android 16 / KernelSU root
用户确认：独立供电 USB 3 Hub；电脑端可正常接收。

最终配置：VHF ADC 16 MS/s，IQ 最高4 MS/s、默认1 MS/s，128×16KiB普通内存USB缓冲。
已验证：固件 RAM 加载、04b4:00f3→04b4:00f1、USB2→USB3配对总线迁移、READY。
固定频率连续采样：1MS/s 30s、2MS/s 20s、4MS/s 20s；USB错误、原始及IQ队列丢样均为0。
调频/增益控制：137.9→138→137.9MHz、gain30→25→30后恢复接收。
调频会主动停流；调频测试累计原始队列丢弃688128个实数样本，不能保证无缝调频。
手机内核 usbcore.quirks 原设置为空，测试后验证已恢复为空。
未验证：OnAir解调听感、HF路径、其他手机、长时间运行。
